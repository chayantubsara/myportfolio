# Public portfolio documents

Files in this directory are published publicly through GitHub Pages.

Recommended structure:

- `resume-public.pdf`
- `certificates/mtcna.pdf`
- `awards/award-name.pdf`
- `projects/project-name.pdf`

Enter paths in Admin without the repository name, for example:

`documents/certificates/mtcna.pdf`

Do not upload files containing a private address, private phone number, IDs, passwords, or other sensitive information.
